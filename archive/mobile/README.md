# Aplicativo mobile arquivado

Este diretório preserva o aplicativo React Native/Expo como referência histórica.
O app não faz parte do produto ativo e não deve ser executado, publicado ou receber
novas funcionalidades. A aplicação web é a única interface ativa do projeto.

O conteúdo foi movido integralmente para cá, incluindo alterações locais existentes,
sem limpeza ou descarte de arquivos.
